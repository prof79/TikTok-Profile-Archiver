# External Dependencies

Rich is used for colorful output:

- [Rich documentation](https://rich.readthedocs.io/en/stable/)

Selenium is used for browser automation:

- [Selenium documentation](https://www.selenium.dev/documentation/)

There are facades for major browsers in `/ttpa/browser` to abstract Selenium usage from specific drivers.

YT-DLP is used for video downloads:

- [YT-DLP codebase and documentation](https://github.com/yt-dlp/yt-dlp)

Reference these when modifying or adding features.
